# 图像掩膜标注系统 (Mask Annotator)

## 项目结构

```
mask_annotator/
├── main.py                  # 入口文件
├── README.md
│
├── core/                    # 核心数据与逻辑层
│   ├── __init__.py
│   ├── config.py            # 全局配置、默认类别定义
│   ├── annotation_state.py  # 标注状态机（当前图、mask、撤销栈等）
│   └── draw_engine.py       # 绘制引擎（面状/线状/橡皮 三种模式）
│
├── ui/                      # UI 层
│   ├── __init__.py
│   ├── main_window.py       # 主窗口
│   ├── graphics_view.py     # 可交互视图（缩放/平移/绘制事件）
│   ├── toolbar_widget.py    # 工具栏区域（模式/工具/笔刷/撤销）
│   ├── class_panel.py       # 类别选择面板
│   └── class_manager_dialog.py  # 类别管理对话框
│
└── utils/                   # 工具函数
    ├── __init__.py
    ├── image_io.py          # 图像读写（支持中文路径）
    └── mask_utils.py        # mask 处理工具（统计、合成显示）
```

## 核心改进

### 高效、安全的连续标注

- 线状笔、面状笔和橡皮擦统一使用“按下左键—拖动—松开”，松开即结束本次笔划。
- 原图作为静态底图，掩膜作为独立透明图层；鼠标拖动时只更新轻量临时笔划，不再重新合成整幅原图。
- 掩膜图层仅在一笔结束、撤销或显示设置变化时更新；类别像素统计仅在一笔结束等低频操作后计算。
- 切图、切换文件夹或退出时，如有未保存修改，会明确提示保存、放弃或取消。
- 底部“保存并下一张”可用于连续处理；没有预先选择掩膜目录时，首次保存会引导选择。
- 标题中的 `*` 和底部黄色状态表示当前标注尚未保存。

### 线状标注模式（裂缝专用）
原版只有「画笔（面状填充）」模式，一次绘制结束后强制 `fillPoly`，导致裂缝变成面状色块。

新版提供四种绘制与编辑工具：

| 工具 | 快捷键 | 适用场景 | 行为 |
|------|--------|---------|------|
| 线状笔 | `1` | 裂缝、裂纹 | 按住左键拖动，松开结束，按实际线宽描边，**不填充** |
| 面状笔 | `2` | 剥落、锈蚀等面状病害 | 按住左键沿边界拖动，松开后自动闭合填充 |
| 橡皮擦 | `3`/`E` | 修正 | 按住左键拖动擦除 |
| 编辑已有多边形 | `4` | 调整已有面状标注 | 单击区域选中，拖动顶点改形，拖动内部整体移动，双击边线添加控制点 |

掩膜文件只保存像素，因此编辑已有多边形时会从点击到的非零连通区域重建外轮廓。一次只编辑一个连通区域，不改变其类别；每次拖动可用 `Ctrl+Z` 完整撤销。对于相互接触且类别相同的区域，栅格掩膜中无法判断原始边界，会被视为同一个连通多边形。

### 其他改进
- 代码拆分为多模块，各层职责清晰
- 绘制过程实时显示已标注范围
- 笔刷宽度对线状标注同样生效（控制裂缝线宽）
- 状态机统一管理当前绘制阶段，易于扩展

## 快捷键

| 键 | 功能 |
|----|------|
| `←` / `A` | 上一张 |
| `→` | 下一张 |
| `W` | 切换掩膜显示 |
| `1` | 切换到线状笔 |
| `2` | 切换到面状笔 |
| `3` / `E` | 切换到橡皮擦 |
| `4` | 编辑已有多边形 |
| `[` / `]` | 减小 / 增大笔刷 |
| `Alt+1`–`Alt+9` | 快速切换病害类别 |
| `F` / `0` | 恢复整图适应窗口 |
| `Esc` | 取消当前正在绘制的笔划 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+S` | 保存掩膜 |
| `Del` | 删除当前图及掩膜 |
| `D` | 保存当前掩膜并进入下一张 |

鼠标滚轮用于缩放，右键拖动用于平移视图。

## 大幅影像说明

当前版本已将原图层与掩膜绘制层分离，解决编辑模式下鼠标每移动一次就扫描和合成整幅影像的问题。为便于评估本阶段的实际改善，掩膜显示层暂时仍是与原图等尺寸的完整图层，尚未引入分块或金字塔显示。
