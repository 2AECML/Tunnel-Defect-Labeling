# 图像掩膜标注系统 (Mask Annotator)

## 项目结构

```
mask_annotator/
├── main.py                  # 入口文件
├── README.md
│
├── core/                    # 核心数据与逻辑层
│   ├── __init__.py
│   ├── config.py            # 全局配置、默认类别定义
│   ├── annotation_state.py  # 标注状态机（当前图、mask、撤销栈等）
│   └── draw_engine.py       # 绘制引擎（线状/面状笔、笔刷/矩形/面状橡皮擦）
│
├── ui/                      # UI 层
│   ├── __init__.py
│   ├── main_window.py       # 主窗口
│   ├── graphics_view.py     # 可交互视图（缩放/平移/绘制事件）
│   ├── toolbar_widget.py    # 工具栏区域（模式/工具/笔刷/撤销）
│   ├── class_panel.py       # 类别选择面板
│   └── class_manager_dialog.py  # 类别管理对话框
│
└── utils/                   # 工具函数
    ├── __init__.py
    ├── image_io.py          # 图像读写（支持中文路径）
    └── mask_utils.py        # mask 处理工具（统计、合成显示）
```

## 核心改进

### 高效、安全的连续标注

- 线状笔、面状笔和橡皮擦统一使用“按下左键—拖动—松开”，松开即结束本次笔划。
- 点击“橡皮擦”，在“擦除方式”中选择笔刷、矩形或面状。软件独立记住最后选择的擦除方式，切换到画笔后再选橡皮擦、关闭再开启编辑、重启软件后再选橡皮擦，均恢复上次的类型。
- 矩形橡皮擦拖动时显示半透明矩形框；面状橡皮擦与面状笔一样只显示实际拖动的边界轨迹，不显示额外的闭合辅助线段。两种区域擦除均在松开后擦除区域内的所有类别标注，原图不变；切换工具或关闭编辑会取消未完成选区。区域擦除不受笔刷宽度影响，可用撤销/重做完整恢复；单击、零面积拖动或仅选中背景不会产生修改记录。
- 原图作为静态底图，掩膜作为独立透明图层；鼠标拖动时只更新轻量临时笔划，不再重新合成整幅原图。
- 掩膜图层仅在一笔结束、撤销、重做或显示设置变化时更新；类别像素统计仅在一笔结束等低频操作后计算。
- `Ctrl+Z` 撤销，`Ctrl+Y` 重做（恢复已撤销操作）；悬浮编辑面板也提供对应按钮。支持连续恢复线状笔、面状笔、橡皮擦、自动填充及多边形编辑/删除，最多保留 20 步。撤销后进行新修改会清除原重做记录；切图或删除掩膜时清空两类历史。
- 切图、切换文件夹或退出时，如有未保存修改，会明确提示保存、放弃或取消。
- 底部“保存并下一张”可用于连续处理；没有预先选择掩膜目录时，首次保存会引导选择。
- 标题中的 `*` 和底部黄色状态表示当前标注尚未保存。
- 自动记住上次选择的原图、掩膜文件夹及成功加载的图像，启动时恢复并优先加载上次的图像；图像不存在时加载第一张，目录不存在时跳过。
- 点击顶部“设置”打开独立设置界面。点击“保存设置”后统一应用并记忆，下次启动时恢复；取消或关闭设置界面不改变已保存的偏好。递归查找、保留目录层级均默认关闭。
  - **图片显示范围**：全部图片（默认）、有掩膜文件、无掩膜文件。按当前掩膜目录和匹配规则判断文件是否存在，全背景掩膜也算有掩膜。上一张、下一张、跳转和计数均使用筛选后的列表；在“无掩膜文件”范围内保存后，已保存图片自动移出列表。
  - **递归查找子目录**：同时在原图和掩膜目录的所有子目录中查找 JPG/JPEG、PNG 等支持的图像，文件列表显示相对路径。
  - **相似填充 → 使用增强图像** 默认关闭。开启后，自动填充、颜色取样和取样后的区域匹配都使用当前亮度、对比度调整后的底图。切换选项或在开启时调整底图，需要重新取样。
  - **保存掩膜时保留目录层级**：开启后将 `原图目录/子目录/图片.jpg` 的掩膜保存为 `掩膜目录/子目录/图片.png`；关闭时保存为 `掩膜目录/图片.png`。递归查找不会自动开启此选项。不同子目录存在同名原图时，建议开启以分别保存标注。
- 查找掩膜优先使用保存选项对应的目录，再查找另一种目录布局；递归模式下也支持其他子目录中的唯一同名掩膜（包括 `_mask` 后缀）。其他目录存在多组同名掩膜时不自动匹配。
- 底部“删除掩膜”仅删除当前图像匹配的掩膜文件，保留原图；没有掩膜文件时按钮禁用。确认后会清除当前未保存标注和撤销记录，并同步刷新显示范围与计数；在“有掩膜文件”范围内，已无掩膜的图片自动移出列表。
- “删除图像与掩膜”按钮删除原图及匹配的掩膜。此操作与“删除掩膜”各自弹出二次确认框，默认选中“取消”。勾选“此次运行中不再提示”并确认删除后，仅对当前这类删除操作免提示，不影响另一类；取消或关闭确认框不生效，重启软件后两类操作均恢复提示。文件删除不可撤销。
- “掩膜叠加”默认快捷键为 `C`，默认采用**长按**模式：按住时临时反转当前显示状态，松开后恢复；也可在设置中改为**点击**模式，每次按键切换一次。模式和快捷键在“保存设置”后自动记忆；切换到其他应用或打开对话框时恢复长按前的状态。鼠标点击“掩膜叠加”仍直接切换显示。
- 应用快捷键见下表，均可在设置中修改并单独“恢复默认”。空值、重复按键和连续多组按键会提示错误，修正后才能保存。点击“保存设置”后统一生效并记忆，取消或关闭不会应用。输入数字、文字或录制快捷键时，保留输入框自身的键盘操作；应用快捷键仅在标注主窗口及其悬浮编辑面板内生效。若新增工具的默认键已被自定义快捷键占用，保留原配置，并为新工具分配一个未占用的组合键。

### 线状标注模式（裂缝专用）
原版只有「画笔（面状填充）」模式，一次绘制结束后强制 `fillPoly`，导致裂缝变成面状色块。

新版提供以下绘制与编辑工具：

| 工具 | 适用场景 | 行为 |
|------|---------|------|
| 线状笔 | 裂缝、裂纹 | 按住左键拖动，松开结束，按实际线宽描边，**不填充** |
| 面状笔 | 剥落、锈蚀等面状病害 | 按住左键沿边界拖动，松开后自动闭合填充 |
| 橡皮擦 | 局部修正 | 按住左键拖动，用可调大小的圆形笔刷擦除 |
| 矩形橡皮擦 | 批量清除矩形范围 | 按住左键从一角拖到对角，松开后擦除框内标注，支持任意拖动方向 |
| 面状橡皮擦 | 按任意边界清除区域 | 像面状笔一样按住左键沿边界拖动，松开后自动闭合并擦除内部标注 |
| 编辑已有多边形 | 调整已有面状标注 | 单击区域选中，拖动顶点改形，拖动内部整体移动，双击边线添加控制点，右击可删除多边形或选中的控制点 |

掩膜文件只保存像素，因此编辑已有多边形时会从点击到的非零连通区域重建精确外轮廓。精确轮廓与初始控制点分开保存：显示轮廓线和掩膜保持真实像素边界，初始控制点采用固定 0.75 像素容差，减少直线、斜直线像素台阶上的冗余点。容差不随周长或点数增大，没有 160 点数量上限，也不会在用户加点后重新压缩控制点。一次只编辑一个连通区域，不改变其类别；每次拖动可用 `Ctrl+Z` 完整撤销。对于相互接触且类别相同的区域，栅格掩膜中无法判断原始边界，会被视为同一个连通多边形。

双击边线仅插入控制点：使用浮点投影坐标，不移动其他点，也不重绘掩膜；点击已有顶点则选中该点，不生成重复点。拖动须按住左键并超过屏幕拖动阈值，双击后的松开事件不会被当作拖动提交。局部顶点编辑仅更新原轮廓与新轮廓的像素差异，保留未改变的边界、孔洞及孔洞中的其他标注。整体移动直接平移原始区域像素；碰到图像边缘时限制整块平移距离，不挤压多边形。

新增共线控制点属于当前编辑状态；重新选中或重开 PNG 时仍按精确像素轮廓重建，并不保存独立的顶点列表。仅加点不会改变掩膜或产生未保存修改。

### 其他改进
- 代码拆分为多模块，各层职责清晰
- 绘制过程实时显示已标注范围
- 笔刷宽度对线状标注同样生效（控制裂缝线宽）
- 状态机统一管理当前绘制阶段，易于扩展

### 相似像素自动填充

#### 取样框选填充

1. 开启编辑，选择病害类别，点击“取样框选填充”。
2. 在原图上按住左键沿样本边界拖动，松开后自动闭合。软件将样本颜色转换到 Lab 空间，通过两组聚类提取代表色。单色样本只保留一个中心，占比不足 10% 的色簇会被舍弃。
3. 选择“矩形范围”或“面状范围”。矩形从一角拖到对角，面状沿边界拖动并在松开时自动闭合。
4. 软件比较选区内背景像素与最近颜色中心的 Lab 欧氏距离，筛选距离在阈值内的像素。按上下左右相邻关系分组后，选出本次候选中像素数最多的一组，舍弃孤立点和其他较小区域。
5. 自动填实最大区域围住的内部空洞，包括颜色超出阈值的背景像素。补洞范围限于选区内的背景像素，与外部相通的凹口保留。

取样填充的 Lab 色差阈值默认 `8`，可在 `0–100` 调整并独立记忆。同一个样本可用于多次选区和阈值调整。点击“重新取样”可更换样本，加载图像时清除样本。每次实际填充都可撤销和重做。

#### 单点连通填充

开启编辑后，选择类别并点击“相似像素自动填充”，再单击目标区域。
色差阈值默认为 `20`，可在 `0–100` 内拖动滑块或在数字框手动输入。点击数字框自动全选原数值，可直接键入替换；每输入一个有效数字即更新阈值、滑块和记忆值，无需回车或移开焦点。切换工具、关闭编辑面板和重启软件后仍保留最后使用的阈值。
候选像素逐通道与点击位置的原图颜色比较；先用 3×3 闭运算连接约 1–2 像素的细缝，
再提取点击位置所在的连通区域，并填满其外轮廓内的空点和孔洞，生成连续的实心标注。
较宽且通向外部的凹口以及远处不连通的相似区域不会被直接纳入。
补齐细缝及内部孔洞时，部分像素可以超出色差阈值。
从背景开始填充时，所有已有标注（包括当前类别）均作为不可穿越、不可覆盖的边界。
采用四邻域传播，避免从已有边界的对角缝隙穿过；补缝和填洞也遵守已有标注边界，
不会填入已有多边形围住且无法从点击位置到达的另一片背景。
单击已有多边形时，先选取被点击的同类别连通区域，补齐约 1–2 像素细缝并填满其外轮廓内
所有空白孔洞；使用该多边形原有类别，不受当前选中类别、原图颜色或色差阈值影响。
只修改背景像素，保留内部其他类别，不处理附近独立的多边形；没有空白需要补齐时不产生修改。
较宽且通向外部的开口仍作为外部边界保留。相接的同类别区域在像素掩膜中视为一个连通多边形。
每次填充均可用 `Ctrl+Z` 完整撤销，原图不变。

## 快捷键

下表为默认值，均可在“设置”的快捷键区域中修改并单独恢复默认。

| 键 | 功能 |
|----|------|
| `A` | 上一张 |
| `D` | 下一张 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做（恢复已撤销操作） |
| `Ctrl+S` | 保存掩膜 |
| `C` | 掩膜叠加：默认按住临时反转、松开恢复；可在设置中改为点击切换 |
| `1` | 切换到线状笔 |
| `2` | 切换到面状笔 |
| `E` | 切换到上次使用的橡皮擦方式 |
| `3` | 切换到相似像素自动填充 |
| `4` | 切换到取样框选填充 |

工具快捷键仅在开启编辑时生效，切换填充工具不会立即修改标注。

鼠标滚轮用于缩放，右键拖动用于平移视图。编辑已有多边形时，在选中区域内单击右键可打开删除菜单。

## 大幅影像说明

当前版本已将原图层与掩膜绘制层分离，解决编辑模式下鼠标每移动一次就扫描和合成整幅影像的问题。为便于评估本阶段的实际改善，掩膜显示层暂时仍是与原图等尺寸的完整图层，尚未引入分块或金字塔显示。
