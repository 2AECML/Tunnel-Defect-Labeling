# 图像掩膜标注系统 (Mask Annotator)

## 项目结构

```
mask_annotator/
├── main.py                  # 入口文件
├── README.md
│
├── core/                    # 核心数据与逻辑层
│   ├── __init__.py
│   ├── config.py            # 全局配置、默认类别定义
│   ├── annotation_state.py  # 标注状态机（当前图、mask、撤销栈等）
│   └── draw_engine.py       # 绘制引擎（面状/线状/橡皮 三种模式）
│
├── ui/                      # UI 层
│   ├── __init__.py
│   ├── main_window.py       # 主窗口
│   ├── graphics_view.py     # 可交互视图（缩放/平移/绘制事件）
│   ├── toolbar_widget.py    # 工具栏区域（模式/工具/笔刷/撤销）
│   ├── class_panel.py       # 类别选择面板
│   └── class_manager_dialog.py  # 类别管理对话框
│
└── utils/                   # 工具函数
    ├── __init__.py
    ├── image_io.py          # 图像读写（支持中文路径）
    └── mask_utils.py        # mask 处理工具（统计、合成显示）
```

## 核心改进

### 新增：线状标注模式（裂缝专用）
原版只有「画笔（面状填充）」模式，一次绘制结束后强制 `fillPoly`，导致裂缝变成面状色块。

新版提供三种绘制工具：

| 工具 | 快捷键 | 适用场景 | 行为 |
|------|--------|---------|------|
| 折线笔（线状） | `1` | 裂缝、裂纹 | 单击添加节点，双击/Enter 结束，按实际线宽描边，**不填充** |
| 面状笔 | `2` | 剥落、锈蚀等面状病害 | 单击起/止，拖动绘路径，结束后 fillPoly 填充 |
| 橡皮擦 | `3`/`E` | 修正 | 长按鼠标擦除 |

### 其他改进
- 代码拆分为多模块，各层职责清晰
- 线状标注时实时预览线段（虚线+节点高亮）
- 笔刷宽度对线状标注同样生效（控制裂缝线宽）
- 状态机统一管理当前绘制阶段，易于扩展

## 快捷键

| 键 | 功能 |
|----|------|
| `←` / `A` | 上一张 |
| `→` / `D` | 下一张（D=保存并下一张）|
| `W` | 切换掩膜显示 |
| `1` | 切换到线状笔 |
| `2` | 切换到面状笔 |
| `3` / `E` | 切换到橡皮擦 |
| `Enter` / 双击 | 结束线状标注 |
| `Esc` | 取消当前正在绘制的线 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+S` | 保存掩膜 |
| `Del` | 删除当前图及掩膜 |
| `1`–`9` | 快速切换病害类别 |
