# 图像掩膜标注系统 (Mask Annotator)

## 项目结构

```
mask_annotator/
├── main.py                  # 入口文件
├── README.md
│
├── core/                    # 核心数据与逻辑层
│   ├── __init__.py
│   ├── config.py            # 全局配置、默认类别定义
│   ├── annotation_state.py  # 标注状态机（当前图、mask、撤销栈等）
│   └── draw_engine.py       # 绘制引擎（面状/线状/橡皮 三种模式）
│
├── ui/                      # UI 层
│   ├── __init__.py
│   ├── main_window.py       # 主窗口
│   ├── graphics_view.py     # 可交互视图（缩放/平移/绘制事件）
│   ├── toolbar_widget.py    # 工具栏区域（模式/工具/笔刷/撤销）
│   ├── class_panel.py       # 类别选择面板
│   └── class_manager_dialog.py  # 类别管理对话框
│
└── utils/                   # 工具函数
    ├── __init__.py

    └── mask_utils.py        # mask 处理工具（统计、合成显示）
```

## 核心改进

### 高效、安全的连续标注

- 线状笔、面状笔和橡皮擦统一使用“按下左键—拖动—松开”，松开即结束本次笔划。
- 原图作为静态底图，掩膜作为独立透明图层；鼠标拖动时只更新轻量临时笔划，不再重新合成整幅原图。
- 掩膜图层仅在一笔结束、撤销或显示设置变化时更新；类别像素统计仅在一笔结束等低频操作后计算。
- 切图、切换文件夹或退出时，如有未保存修改，会明确提示保存、放弃或取消。
- 底部“保存并下一张”可用于连续处理；没有预先选择掩膜目录时，首次保存会引导选择。
- 标题中的 `*` 和底部黄色状态表示当前标注尚未保存。
- 自动记住上次选择的原图、掩膜文件夹及成功加载的图像，启动时恢复并优先加载上次的图像；图像不存在时加载第一张，目录不存在时跳过。
- 点击顶部“设置”打开独立设置界面。点击“保存设置”后统一应用并记忆，下次启动时恢复；取消或关闭设置界面不改变已保存的偏好。递归查找、保留目录层级均默认关闭。
  - **图片显示范围**：全部图片（默认）、有掩膜文件、无掩膜文件。按当前掩膜目录和匹配规则判断文件是否存在，全背景掩膜也算有掩膜。上一张、下一张、跳转和计数均使用筛选后的列表；在“无掩膜文件”范围内保存后，已保存图片自动移出列表。
  - **递归查找子目录**：同时在原图和掩膜目录的所有子目录中查找 JPG/JPEG、PNG 等支持的图像，文件列表显示相对路径。
  - **保存掩膜时保留目录层级**：开启后将 `原图目录/子目录/图片.jpg` 的掩膜保存为 `掩膜目录/子目录/图片.png`；关闭时保存为 `掩膜目录/图片.png`。递归查找不会自动开启此选项。不同子目录存在同名原图时，建议开启以分别保存标注。
- 查找掩膜优先使用保存选项对应的目录，再查找另一种目录布局；递归模式下也支持其他子目录中的唯一同名掩膜（包括 `_mask` 后缀）。其他目录存在多组同名掩膜时不自动匹配。

### 线状标注模式（裂缝专用）
原版只有「画笔（面状填充）」模式，一次绘制结束后强制 `fillPoly`，导致裂缝变成面状色块。

新版提供四种绘制与编辑工具：

| 工具 | 快捷键 | 适用场景 | 行为 |
|------|--------|---------|------|
| 线状笔 | `1` | 裂缝、裂纹 | 按住左键拖动，松开结束，按实际线宽描边，**不填充** |
| 面状笔 | `2` | 剥落、锈蚀等面状病害 | 按住左键沿边界拖动，松开后自动闭合填充 |
| 橡皮擦 | `3`/`E` | 修正 | 按住左键拖动擦除 |
| 编辑已有多边形 | `4` | 调整已有面状标注 | 单击区域选中，拖动顶点改形，拖动内部整体移动，双击边线添加控制点，右击可删除多边形或选中的控制点 |

掩膜文件只保存像素，因此编辑已有多边形时会从点击到的非零连通区域重建精确外轮廓。精确轮廓与初始控制点分开保存：显示轮廓线和掩膜保持真实像素边界，初始控制点采用固定 0.75 像素容差，减少直线、斜直线像素台阶上的冗余点。容差不随周长或点数增大，没有 160 点数量上限，也不会在用户加点后重新压缩控制点。一次只编辑一个连通区域，不改变其类别；每次拖动可用 `Ctrl+Z` 完整撤销。对于相互接触且类别相同的区域，栅格掩膜中无法判断原始边界，会被视为同一个连通多边形。

双击边线仅插入控制点：使用浮点投影坐标，不移动其他点，也不重绘掩膜；点击已有顶点则选中该点，不生成重复点。拖动须按住左键并超过屏幕拖动阈值，双击后的松开事件不会被当作拖动提交。局部顶点编辑仅更新原轮廓与新轮廓的像素差异，保留未改变的边界、孔洞及孔洞中的其他标注。整体移动直接平移原始区域像素；碰到图像边缘时限制整块平移距离，不挤压多边形。

新增共线控制点属于当前编辑状态；重新选中或重开 PNG 时仍按精确像素轮廓重建，并不保存独立的顶点列表。仅加点不会改变掩膜或产生未保存修改。

### 其他改进
- 代码拆分为多模块，各层职责清晰
- 绘制过程实时显示已标注范围
- 笔刷宽度对线状标注同样生效（控制裂缝线宽）
- 状态机统一管理当前绘制阶段，易于扩展

### 相似像素自动填充

开启编辑后，选择类别并点击“相似像素自动填充”（快捷键 `5`），再单击目标区域。
色差阈值默认为 `20`，可在 `0–100` 内调整，也可用 `[` / `]` 减小或增大。
候选像素逐通道与点击位置的原图颜色比较；先用 3×3 闭运算连接约 1–2 像素的细缝，
再提取点击位置所在的连通区域，并填满其外轮廓内的空点和孔洞，生成连续的实心标注。
较宽且通向外部的凹口以及远处不连通的相似区域不会被直接纳入。
补齐细缝及内部孔洞时，部分像素可以超出色差阈值。
从背景开始填充时，所有已有标注（包括当前类别）均作为不可穿越、不可覆盖的边界。
采用四邻域传播，避免从已有边界的对角缝隙穿过；补缝和填洞也遵守已有标注边界，
不会填入已有多边形围住且无法从点击位置到达的另一片背景。
单击已有多边形时，先选取被点击的同类别连通区域，补齐约 1–2 像素细缝并填满其外轮廓内
所有空白孔洞；使用该多边形原有类别，不受当前选中类别、原图颜色或色差阈值影响。
只修改背景像素，保留内部其他类别，不处理附近独立的多边形；没有空白需要补齐时不产生修改。
较宽且通向外部的开口仍作为外部边界保留。相接的同类别区域在像素掩膜中视为一个连通多边形。
每次填充均可用 `Ctrl+Z` 完整撤销，原图不变。

## 快捷键

| 键 | 功能 |
|----|------|
| `←` / `A` | 上一张 |
| `→` | 下一张 |
| `W` | 切换掩膜显示 |
| `1` | 切换到线状笔 |
| `2` | 切换到面状笔 |
| `3` / `E` | 切换到橡皮擦 |
| `4` | 编辑已有多边形 |
| `[` / `]` | 减小 / 增大笔刷 |
| `Alt+1`–`Alt+9` | 快速切换病害类别 |
| `F` / `0` | 恢复整图适应窗口 |
| `Esc` | 取消当前正在绘制的笔划 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+S` | 保存掩膜 |
| `Ctrl+D` | 删除选中的控制点；未选中点时删除当前多边形 |
| `Del` | 删除当前图及掩膜 |
| `D` | 保存当前掩膜并进入下一张 |

鼠标滚轮用于缩放，右键拖动用于平移视图。编辑已有多边形时，在选中区域内单击右键可打开删除菜单。

## 大幅影像说明

当前版本已将原图层与掩膜绘制层分离，解决编辑模式下鼠标每移动一次就扫描和合成整幅影像的问题。为便于评估本阶段的实际改善，掩膜显示层暂时仍是与原图等尺寸的完整图层，尚未引入分块或金字塔显示。
